Entry for [make.fun](https://make.fun/r/41fw6r6c) competition `u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb`.

Runs on Node 22.18+ (`program/v1`) and writes a deterministic, gate-verified 100-word villain monologue to `/output/entry.txt`:

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
